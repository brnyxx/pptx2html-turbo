# v2.0.0 Validation Report

This report separates repository-reproducible release gates from operator-observed proxy rendering evidence.
LibreOffice and Chromium results are regression signals only and do not authorize an `exact` capability promotion.

## Repository-Reproducible Gates

The v2.0.0 release candidate is checked with:

```bash
cargo fmt --all -- --check
cargo check --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
cargo build --release --workspace
python3 -m unittest discover -s evaluate/tests -p 'test_*.py' -v
python3 evaluate/check_completeness_manifest.py \
  --manifest evaluate/completeness_manifest.json \
  --repo-root .
python3 evaluate/check_preset_adjustments.py --repo-root .
python3 evaluate/check_exactness_contract.py --repo-root .
```

The exactness contract reports 56 registered capabilities, zero semantic `unparsed` entries, and zero `exact` dimensions.
The preset contract reports 187 classified presets, 300 official preset/adjustment pairs, zero unknown consumed keys, and zero unused manifest keys.
The evaluation suite completes 214 tests after installing its canonical dependency set and Chromium runtime.
The CLI is also checked with stable Clippy for the `x86_64-pc-windows-msvc` target so Windows-only APIs cannot bypass release validation.

Release packaging also covers:

- A locally built and installed Python wheel with all binding smoke tests.
- A web-target WASM package with package-contract, package-root import, and runtime smoke tests.
- `npm publish --dry-run --access public` for `@briank-dev/pptx2html-turbo@2.0.0`.
- Release CLI `--version`, `--help`, successful real-deck conversion, and missing-input behavior.
- The locally assembled GitHub Pages artifact in real Chrome plus Playwright Firefox and WebKit.

Each browser loaded the WASM module, rejected an invalid extension, converted the same real 10-slide deck, displayed 571 ordered diagnostics, executed two generated scripts in an opaque-origin output frame, and produced no console or page errors.
The parent page had no horizontal overflow at a 375 px viewport.
