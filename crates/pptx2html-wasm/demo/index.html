PPTX to HTML, without a server.

pptx2html-turbo is a from-scratch ECMA-376 renderer written in Rust and compiled to WebAssembly. Drop a deck below and it is unzipped, parsed, resolved against its layout and master, and drawn as positioned HTML. Nothing is uploaded.

    How a slide becomes a page

    five passes

    Each pass is a crate module, and the same code runs in the CLI, the Python bindings, and here.

    Unzip

    parser / opc

    A .pptx is an Open Packaging Convention archive. The ZIP central directory is read in memory and relationship parts are followed to reach slides, layouts, masters, and the theme.

    Parse

    parser / xml

    quick-xml walks every part as a stream of SAX events rather than building a document tree, which keeps a large deck inside a small, predictable memory envelope.

    Resolve

    resolver

    Every property walks the inheritance chain in order: shape, layout placeholder, master placeholder, txStyles, defaultTextStyle, then the specification default. Colours resolve through the slide colour map into the theme.

    Measure

    model / units

    English Metric Units become CSS pixels at 914400 EMU to the inch. Geometry stays absolute, so scaling the slide behaves like scaling an image and text never reflows.

    Render

    renderer

    Shapes, text runs, tables, and preset geometry are emitted as positioned HTML with inline SVG paths. Anything the renderer cannot resolve is recorded as a coded diagnostic instead of being dropped.

    What the renderer resolves

    implemented, not stubbed
    Behaviour is implemented directly from the ECMA-376 specification; no reference implementation is translated.
    AreaBehaviour
    Theme coloursTwelve modifiers resolved through the slide colour map, including tint, shade, lumMod, and satMod, with layout-level overrides honoured.
    InheritanceSlide to layout to master to theme, with placeholders matched by type and index at every level.
    Preset shapes187 geometries rendered as SVG with adjust values. An unresolved custom guide formula is preserved verbatim and reported rather than substituted with zero.
    TextRuns, paragraph properties, bullet definitions, body insets, and autofit hints, kept in absolute boxes so line breaks match the source.
    Tables and groupsCell spans, borders, and fills from the table style part; nested group shapes with their own child coordinate spaces.
    ImagesEmbedded parts are inlined as base64 by default with source cropping applied, or written alongside the document when external mode is selected.
    DiagnosticsEvery fallback carries a stable code and an order, so coverage gaps stay countable instead of silent. Convert a deck above to see the ones your own file produces.

    Use it outside this page

    same core, three surfaces

    Browser

    # install
npm i @briank-dev/pptx-to-html
// render into a sandboxed frame
import { pptxToHtml } from
  '@briank-dev/pptx-to-html';
frame.srcdoc = await pptxToHtml(file);

    Command line

    # binaries ship with each release
pptx2html deck.pptx -o deck.html
pptx2html deck.pptx --slides 1,3,5-8
pptx2html deck.pptx --scale 2.0
pptx2html deck.pptx --diagnostics d.json

    Python

    # bindings built with maturin
import pptx2html
html = pptx2html.convert_file("deck.pptx")
out = pptx2html.convert_with_metadata(
    "deck.pptx")
print(len(out.diagnostics))
